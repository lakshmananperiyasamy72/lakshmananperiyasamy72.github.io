# Custom Icons & Favicon Directory

Store brand marks, custom SVGs, and favicon variations here.

### 📋 Files Present:
- `favicon.svg`: Vector SVG favicon (<LP/> monogram with Electric Lime `#B6F36B` accent) used in browser tabs and mobile bookmarking.

### 📋 Additional Supported Files:
- `apple-touch-icon.png` (180x180 px for iOS home screens)
- `icon-192.png` & `icon-512.png` (PWA Web App Manifest icons)
