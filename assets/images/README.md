# Profile Photographs Directory

Place your authentic professional photograph here.

### 📋 Recommended Specifications:
- **File Name:** `profile.jpg` or `profile.png`
- **Dimensions:** 800 x 800 px (1:1 square ratio) or 800 x 1000 px (4:5 portrait)
- **Format:** JPG, PNG, or WebP
- **Background:** Clean solid or studio dark backdrop matching the portfolio palette (`#0B0D10` / `#12151A`)
- **Attire:** Business casual or formal professional

### 🔄 How the Portfolio Renders It:
Once you add `profile.jpg` into this folder, the portfolio will automatically render your photograph within the dedicated portrait frame in the About Me section, complete with a subtle Electric Lime (`#B6F36B`) ambient glow border. Until provided, the portfolio gracefully displays the verified developer telemetry visual.
